## Why the heel does not come: heel_pitch has no slope where the paw is

`heel_tail.py` scores heel_pitch's shape per paw-down frame (as
`orun14/heel_meta.py`, its calibration read on v05-s1's gallop bundle,
the same model: `_META` = `c_meta` world pitch + 63.90°, spread 0.00):

| evaluation | `_META` median heel up LH / RH | cubic 16 (now): mean pay LH / RH; slope there | ×3 weight: slope there | + 0.3 tent 90: mean pay LH / RH; slope there |
|---|---|---|---|---|
| sg-s2-25-2400 | +62.1 / +22.5 | 0.03 / 0.14; 0.000 / 0.000 | 0.000 / 0.000 | 0.15 / 0.38; 0.003 / 0.003 |
| sg-s2-50-1000 | – | 0.17 / 0.05; 0.000 / 0.000 | 0.000 / 0.000 | 0.37 / 0.20; 0.003 / 0.003 |
| sg-s2-50-2400 | +24.0 / +40.0 | 0.22 / 0.07; 0.000 / 0.000 | 0.000 / 0.000 | 0.45 / 0.26; 0.003 / 0.003 |
| sg-s1-50-2400 (heels down 0.91 / 0.58) | +7.4 / +8.9 | 0.83 / 0.72; 0.157 / 0.125 | 0.471 / 0.375 | 1.13 / 1.01; 0.160 / 0.128 |

The cubic (half-width 16° about +6°) pays nothing and has no slope 22–62°
off its peak, where sg-s2's heel-up stance sits, so the critic's example
lever, a larger weight with the command, multiplies zero. A tent of
half-width 90° at 0.3 of the weight pays a slope towards the flat
wherever the clip has the hind down, and leaves the heel-down pay
nearly as it was (1.04 against 0.75, ×1.4) — 60° (also scored) gives no
slope at sg-s2-25-1700's LH (+78.7).
