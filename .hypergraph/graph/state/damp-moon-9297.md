- [scope: temporary worker bundle encountered during the tally correction | confidence: high | evidence: windy-dune-3488] One content-addressed bundle held old worker bytes and caused import failures; quarantining it restored the final gates without changing cache code. Cache invalidation remains uninvestigated. Staging must finish before suites that inspect the payload run.

- [scope: accepted pan-tilt rerun artifact at revision `8ad39702…`, catalog-stamped published-output scan | confidence: high | evidence: odd-ridge-9607] Both fused MG90S are absent as separate outputs and all 14 outputs lack catalog stamps. Scanning those outputs cannot recover their identities; generator-call totals are not evidence of actually used parts.

- [scope: named-angle probe using the existing background Blender renderer after accepted hinged-arm hydration | confidence: high | evidence: zesty-aspen-6846] All four valid blueprint views and `render_views` explicitly refuse background mode. The override probe's exit 0 records returned errors, not a rendered PNG. CPU projection must snapshot revision-dependent display buffers before another rebuild invalidates their paths.

- [scope: inventory inspection replies exceeding the 1 KiB per-key budget | confidence: high | evidence: lawful-ivy-4474] Paging only `/components` is insufficient: catalog totals, uncatalogued sources, component rows and nested strings can also be previews. The former reader failed converting `/catalog_counts` to an integer and could lose oversized names; recursive expansion is required and regression-tested.

- [scope: `_measure_clearance` on an `App::Link` whose linked object carries its own placement — every `lib.*`-placed catalog part | confidence: high | evidence: empty-banner-7438, light-timber-5868] `App::Link` replaces the source's placement rather than composing it, and `Part.getShape(link)` does the same; only a link to an `App::Part` container composes. `SimpleNamespace`-stubbed tests cannot see this, which is why three earlier walks on hand-modelled parts never did. Fixed for the pair check by composing `component.Placement * shape.Placement`, pinned by a real-kernel regression that fails on the old source.
- [scope: `_clearance_at_frame`, the swept clearance inside the simulation trace, for `lib.*`-placed bodies | confidence: high | evidence: light-timber-5868, southern-otter-5999] Had the same link-shape frame defect and was left by ADR-241 pending a cost measurement. Closed by ADR-242: with the composed copy hoisted out of the frame loop the sweep is no slower (faster under box rejection), and the pre-fix source reported a straight-through collision as 33.0 mm of clearance. The measurement, not the guess, is what licensed the fix.
- [scope: a structural check stated as a conditional over `lib.*`-placed rows | confidence: high | evidence: morning-summit-7848] The design turn is nondeterministic: the same pan-tilt prompt that placed two catalog servos once fused them into hand-authored solids the next time (0 catalogued). A conditional with an empty antecedent is vacuously true, and reporting that as a pass is the same class of lie as the defect it checks for. Record it as a null result and get the evidence from an assembly that actually carries placed catalog parts.
- [scope: the installed bundle between commit `cf3b77a6` and the 2026-09-08 refresh | confidence: high | evidence: light-timber-5868, morning-summit-7848] Was stale by one Python file and reported the pre-fix clearance numbers under `--engine <bundle>`. Closed by the refresh; the worker is now byte-identical across source, payload and bundle. A Python-only engine change still needs `build-shell` (which stages) plus the install script before the bundle sees it.
