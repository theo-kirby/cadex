# Cadex v0.0.1 — 2026-07-24

The first release that embodies the product vision in miniature: a lean
source tree, **one project script** as the sole source of truth, and a
locked-down 50/50 chat-driven shell. Phases 1–3 of `docs/ROADMAP.md`, in
full. No installers; run from source (`pixi run build-release` +
`pixi run install-release` + `pixi run freecad-release`).

## Phase 1 — Source-tree reduction

- 17 unused workbench trees deleted (batch A: AddonManager, BIM, CAM, Fem,
  Inspection, OpenSCAD, Plot, ReverseEngineering, Robot, Surface, Tux, Web,
  TemplatePyMod; batch B: Draft, Points, TechDraw, Spreadsheet), each via
  the audited disable-then-delete protocol (ADR-007, ADR-009).
- The assembly bill-of-materials feature was dropped end to end — it was
  the only consumer of Spreadsheet (ADR-008).
- The viewport grid is cadex-owned (pivy two-tier line grid with the
  adaptive-scale controller); the Draft dependency is gone.
- ~18k lines of dead culled-domain code swept from the engine (ADR-010).
- Remaining `src/Mod/` trees are all load-bearing: the four capability
  workbenches plus support trees (`docs/FREECAD.md`).

## Phase 2 — One project script

- THE artifact is `<project>/script.py`: one declarative Python program
  composing sketcher, part, partdesign, and assembly, with parameters
  declared in-script (`params`/`num`). State rides
  `script.json` (`cadex-project-script-v1`) — spec cache, values,
  revisions, accepted contract, accepted digest (ADR-011).
- One multi-domain worker executes the script in a sandboxed headless
  `FreeCADCmd` subprocess; one publication pass applies all domains under
  ONE transaction with ownership lint (`PUBLICATION_UNTAGGED_OBJECT`) and
  orphan GC (ADR-012).
- The provider tool surface is exactly
  `xscript.project.{describe_api, write_script, edit_script, set_params}`;
  the per-domain multi-program lifecycle is gone, as is the editable Model
  Code Editor (ADR-013).
- Parameter sliders bind to the script's declared specs and commit through
  `set_params` with revision guards (ADR-014).
- The document is a rebuildable artifact: `pixi run rebuild <root>`
  re-runs the script headlessly and verifies the content digest; the
  digest CI (`CadexProjectRebuildDigest`) proves delete-document →
  rebuild → digest-matches, twice.

## Phase 3 — UX convergence

- 50/50 shell: viewport left; right column tree / parameters / read-only
  script view / chat, held by a `resizeDocks` event filter (ADR-015).
- Native routes are locked down: one minimal menu (About / Preferences /
  Quit — Preferences remains reachable for API keys), all other shortcuts
  stripped, tree context menus and double-click edits blocked, and an edit
  watchdog that closes any native edit session the tools did not sanction.

## Known limitations

- **No migration** of pre-release per-domain program stores: conversations
  are preserved; scripts start empty (ADR-011).
- **Assemblies are rigid, same-script solids** — cross-document component
  references and flexible subassemblies are out of scope.
- **The bill-of-materials feature is removed** (ADR-008); a parts table
  can return later on a cadex-owned substrate.
- **The Qt shell is interim and disposable** — the endpoint is a Blender
  shell over a headless engine (`docs/INTEGRATION.md`); Coin3D/Qt
  investment stays capped.
- `version.json` keeps `name: "FreeCAD"`: renaming shifts the CMake
  project name and the appdata directory anchoring project roots — a
  separate decision.
