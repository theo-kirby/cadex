## What

A whole-repository stale-doc pass after ADR-536 to ADR-539: about 45 living docs were checked against the source and corrected. Six parallel agents each owned a disjoint file set. A few stale code comments were also fixed (`remote_train.sh`, `CadexDynamics.py`, `report.py`, `tools.py`, `pixi.toml`).

## Why

Owner request (2026-10-04): "go through everything in the project and update all the stale docs". ADR-498 (the shell deleted), ADR-536 (Ouroboros out), ADR-537 (a read-only dashboard) and ADR-538 (no built-in agent) left docs that described the shell, the Training and Policy Outputs panels, `cadex -p`, `walk --prompt`, dashboard chat, comments and writes, and run pages as present.

## Method

Commit `e5fe978f`.

Rules: code wins; dated history stays but must not read as current instruction; `Verified against source:` is bumped on changed files. `DECISIONS.md`, `STATE.md`, `docs/history`, `docs/probes`, `.hypergraph` and `.ouroboros` were not touched. Each agent ran the tests that reference its files. Both full suites ran afterwards.

## Result

- **Living docs corrected:** MUJOCO, training README and SETUP, CLI, DASHBOARD, INTEGRATION, ROADMAP, VISION, IDEAS, SECURITY, PRIVACY_POLICY, CONTRIBUTING, the PR template (it was still FreeCAD's), XSCRIPT, ARCHITECTURE, guidance header, .hypergraph/AGENTS, PROVENANCE, FREECAD, release packaging, THIRD_PARTY_LICENSES, SHELL-PARITY (21 cited tests no longer existed), analysis README, STRUCTURAL, ORGANIC and DESIGN-LANGUAGE.
- **Ten point-in-time audits** got a dated-record line under their titles, with bodies intact.
- **SETUP.md:** nothing in the product reads `<project>/training-progress.json` except `cadex walk --complete`; the dashboard plots `runs/<run>/train/progress.json`.

Left for the owner:
- PLAN.md says it is generated by a tool that does not exist.
- SECURITY says "no release", while `docs/releases/v0.0.1.md` exists.
- NOTICE still credits the OpenTheme themes deleted with `src/Gui`.
- The guidance and DESIGN-LANGUAGE still say "looks engineered", against the owner's recorded taste.
- CI's engine unit suite has failed since about 2026-09-29.
- Nine audit docs are candidates for `docs/history/`.
