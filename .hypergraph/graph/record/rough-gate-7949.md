## Method

First record the four existing servo identities and distinguish the remaining breadth counts without repeating the completed L3 audit. Qualify one genuinely distinct fifth positional hobby-servo SKU representable by the existing ServoPart contract. Inspect manufacturer documents for exact variant, voltage-qualified stall torque, mounting centres/holes, output-axis and envelope datums; distinguish sourced dimensions from explicit cosmetic approximations, stall from continuous torque, and geometry from fit/dynamics claims. At most two new candidates; no RI50, AT2814, solenoid or manufacturer-horn search. Record URLs, document identities and hashes, source conflicts, the precise acceptance contract and real-worker test commands. No runtime edit or guessed nominal interface. If neither qualifies, record exact gaps and request replanning through the work record; later ranks do not run.

Second, conditional on source qualification, independently prove canonical and rotated/translated interface geometry with real OCCT. Use source-derived dimensions and material/void or surface checks rather than only bounds/volume or self-comparison. Keep this a proof/test unit, no public SKU delivery; tests remain green on the current product and temporary standalone probes may provide the candidate evidence. Document reusable recipe compatibility and refusal/approximation limits. If an incompatible new abstraction is needed, stop and record the reason rather than enlarging scope.

Third, conditional on both records, add only that SKU using existing servo discovery and recipe behavior. Add meaningful catalog/torque-unit and actual-worker geometry/publication checks, run the full engine suite, at most one build-engine, finish stage-engine before packaged lifecycle/library tests, and report skips/failures and local relocation limits honestly. Update provenance, dates, ADR/ROADMAP and one work record with real impacts. Do not claim all breadth, L3, horn STEP or powered-robot criteria from this delivery. Every unit has one coherent commit plus one record; no remote work, GUI launch or license-boundary crossing.

Rewrite all three plan bodies with compare-and-swap, retaining negative knowledge and existing long obligations. Advance only the plan mark, export/sync/check and commit. No code, charter, old record, state node or STATE.md changes.
