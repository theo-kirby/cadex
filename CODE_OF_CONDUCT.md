# Cadex Code of Conduct

Verified against source: 2026-08-29

This replaces the FreeCAD Project code of conduct the fork inherited,
whose enforcement routes pointed at FreeCAD's forum team. Cadex is a small
experimental project; its code of conduct fits in one screen.

**Be excellent to each other.**

- **Be respectful.** Disagreement is healthy; personal insults,
  intimidation and threats are not. Keep it professional.
- **Be considerate.** Contributors come from different backgrounds and
  many write English as a second language. Read charitably.
- **Be forgiving.** People make mistakes and change their minds. Assume
  good faith; help each other learn rather than assigning blame.

This applies in project spaces (issues, pull requests, discussions) and
wherever someone is representing the project.

Unacceptable behavior can be reported to the repository owner via GitHub.
Reports are handled confidentially. The maintainers may remove, edit or
reject contributions that violate this code, and may block repeat or
egregious offenders.

Adapted in spirit from the [Contributor
Covenant](https://www.contributor-covenant.org) and FreeCAD's own code of
conduct, which this file replaces.
